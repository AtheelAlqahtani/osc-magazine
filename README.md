# BS Operations and Supply Chain: Program Magazine

KFUPM Business School · 2026

A page-turning magazine version of the BS Operations and Supply Chain degree plan.
Swipe, drag, click or use the ← → keys to turn pages.

## Publish on GitHub Pages

1. Create a new public repository named **`osc-magazine`** (this exact name, so the brochure QR code works).
2. Click **Add file → Upload files** and drag in every file in this folder (`index.html`, `favicon.png`, `README.md`).
3. Click **Commit changes**.
4. Open **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
5. After a minute or two the magazine is live at `https://atheelalqahtani.github.io/osc-magazine/`.
